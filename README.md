# Lootora Clicker

Lootora — браузерная dark-fantasy clicker RPG: сражения с боссами, прокачка охотника, оружие семи редкостей, питомцы, подземелья, башня, ежедневные события и рейтинг.

## Что уже работает
- Регистрация и вход через прежний Supabase Auth.
- Стартовый запас — 1 000 игрового золота.
- Кликер-битва: урон, критические удары, здоровье боссов, опыт и уровни.
- Улучшения оружия, автоатаки и критического шанса.
- Боссы: гигантские монстры, демоны, драконы, магические короли и космические существа.
- Инвентарь семи редкостей с модификаторами, питомцы, ежедневное задание, подземелья и башня.
- Интерфейс разделов PvP, гильдий, турниров, чата и топ-10.

## Баланс выпадений

Это базовые веса внутри пула редкостей, доступного у конкретного босса. Слабые боссы ограничены обычными и редкими предметами; более сильные постепенно открывают более высокие редкости.

| Редкость | Базовый вес |
|---|---:|
| Обычная | 58% |
| Редкая | 28% |
| Сверхредкая | 11% |
| Эпическая | 3% |
| Мифическая | 0,8% |
| Легендарная | 0,18% |
| Секретная | 0,02% |

Цвета: серый, светло-зелёный, синий, фиолетовый, красный, золотой и чёрный. Модификаторы включают «Сломанный», «Древний», «Проклятый» и «Скованный богами». Это стартовая настройка баланса для дальнейшего тестирования.

## Подключение облачного сохранения, топ-10 и чата

1. Открой [Supabase SQL Editor](https://supabase.com/dashboard/project/vuxgkadarbikiftetqwv/sql/new).
2. В репозитории открой файл [supabase-clicker.sql](supabase-clicker.sql).
3. Скопируй весь SQL, вставь в Supabase SQL Editor и нажми **Run**.
4. Обнови Lootora и войди в аккаунт.

SQL создаёт таблицу облачных сохранений lootora_clicker_saves и таблицу общего чата lootora_chat, включает RLS и политики доступа. Рейтинг доступен для чтения, игрок может менять только собственное сохранение.

## Что ещё не подключено

- Облачные сохранения и топ-10 заработают после выполнения SQL.
- PvP, совместные рейд-боссы, гильдии и автоматическая выдача турнирных наград пока представлены интерфейсом; для них нужен отдельный серверный API, подбор соперников и защита от подмены результатов.
- Пока локальная версия сохраняет прогресс в браузере. При входе она пытается загрузить облачное сохранение.
- Золото и предметы — игровые данные без реальной денежной стоимости и вывода средств.
