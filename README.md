# Lootora

Фронтенд игрового маркетплейса на GitHub Pages.

## Уже добавлено
- адаптивный интерфейс каталога и поиск по товарам;
- категории игровых товаров и карточки с изображениями;
- форма публикации товара (пока демонстрационная, без сохранения в базе);
- интерфейс входа и регистрации по email/паролю через Supabase Auth;
- проверка сессии, выход из аккаунта и запрос сброса пароля.

## Подключение настоящей регистрации

Для регистрации нужен собственный проект Supabase. Без его URL и публичного ключа регистрация не может работать — один GitHub Pages не хранит пользователей и не предоставляет сервер авторизации.

1. Создайте проект на https://supabase.com/dashboard.
2. В настройках проекта откройте раздел API / Connect и скопируйте **Project URL** и **publishable key** (или legacy **anon** key).
3. Откройте опубликованный сайт, нажмите «Войти», раскройте «Настройка сервиса аккаунтов» и вставьте эти два значения.
4. В Supabase → Authentication → URL Configuration добавьте в Site URL и Redirect URLs адрес сайта: `https://vpn86156-ctrl.github.io/weatherly/`.
5. В Authentication → Providers убедитесь, что Email включён. При включённом подтверждении email пользователю придёт письмо для активации.

На странице ключ хранится в localStorage браузера. Publishable/anon key предназначен для клиентского приложения; **никогда не используйте и не публикуйте service_role key**.

Официальные инструкции:
- https://supabase.com/docs/guides/auth
- https://supabase.com/docs/reference/javascript/auth-signup

## Текущие ограничения

- Регистрация и вход подключаются к Supabase только после добавления Project URL и publishable/anon key.
- Каталог и новые объявления пока не сохраняются в базе данных; товары остаются демонстрационными.
- Не реализованы заказы, чат, модерация, споры, безопасная сделка, реальные платежи и выплаты.
- Баланс и комиссия в интерфейсе не являются реальными финансовыми операциями.

До запуска торговли товарами сторонних продавцов и выплат необходимо согласовать юридическую модель и подходящий налоговый режим. Самозанятость НПД в общем случае не подходит для перепродажи чужих товаров и посреднической/агентской деятельности. Не принимайте деньги покупателей на личную карту и не обещайте вывод демонстрационного баланса.
