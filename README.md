# Lootora

Демонстрационный frontend игрового маркетплейса на русском языке.

## Что есть сейчас
- адаптивная главная страница;
- каталог и фильтры по играм;
- поиск по товарам и продавцам;
- демонстрационные карточки товаров;
- форма добавления объявления (данные хранятся только в памяти страницы);
- макет кошелька продавца с планируемой комиссией 7%.

## Запуск
Откройте `index.html` в браузере. Проект публикуется через GitHub Pages.

## Важно
Это пока frontend-прототип. Регистрация, сервер, база данных, реальные заказы,
оплата, безопасная сделка, споры и выплаты не реализованы. Баланс на странице
демонстрационный и не является денежными средствами.

До запуска торговли товарами сторонних продавцов и выплат необходимо согласовать
юридическую модель и подходящий налоговый режим. Самозанятость НПД не подходит
для перепродажи чужих товаров и посреднической/агентской деятельности в общем случае.
Не принимайте деньги покупателей на личную карту и не обещайте продавцам вывод
демонстрационного баланса.

## Следующие этапы
1. Сервер и PostgreSQL.
2. Регистрация, авторизация и роли покупателей/продавцов/администраторов.
3. Объявления, заказы, сообщения, модерация и система споров.
4. Неизменяемый журнал финансовых операций и возвраты.
5. Подключение платёжного провайдера, который письменно согласует маркетплейсную
   модель, удержания и выплаты продавцам.
6. Проверка безопасности, политика конфиденциальности и пользовательские документы.
