# Lootora

Lootora — браузерная многопользовательская игра с виртуальной экономикой, предметами, репутацией, ежедневными соревнованиями и игровым чатом.

## Игровой центр
- Сохранена регистрация и вход через Supabase Auth.
- Стартовый виртуальный баланс 1 000 ₽.
- Каталог расширен демонстрационными предметами.
- Игровой центр: профиль, репутация, чат, TOP-10 и настройки.
- Ежедневный торговый марафон: очки за тренировочные действия, лимит 20 очков в день.
- Рискованная игровая механика: отправка предложения другому игроку; получатель принимает или отклоняет, результат вычисляется на сервере.
- Жалобы на игроков.

## Обязательная настройка игровой базы
Чтобы общий чат, профиль, рейтинг и риск-механика работали между реальными аккаунтами, один раз выполни SQL:
1. Открой [Supabase SQL Editor](https://supabase.com/dashboard/project/vuxgkadarbikiftetqwv/sql/new).
2. Открой файл [supabase/lootora_game.sql](supabase/lootora_game.sql), скопируй весь текст и вставь в редактор.
3. Нажми **Run**, затем обнови Lootora и войди в аккаунт.

SQL создаёт профили со стартовыми 1 000 виртуальных рублей, таблицы чата, жалоб, рискованных предложений и дневного рейтинга. Для существовавших аккаунтов создаются профили. Включён Row Level Security; изменения виртуального баланса и репутации проводятся серверными функциями.

## Регистрация
Регистрация остаётся на Supabase Auth. Project URL уже настроен в клиенте: `https://vuxgkadarbikiftetqwv.supabase.co`. В Supabase → Authentication → URL Configuration укажи Site URL и Redirect URL: `https://vpn86156-ctrl.github.io/weatherly/`. Используется только публичный publishable key. Никогда не публикуй service_role/secret key.

## Ограничения прототипа
- Призы в марафоне показаны как планируемые игровые награды; автоматическая выдача ещё не сделана.
- Очки пока начисляются за тренировочную сделку, это не полноценная система торговли между игроками.
- Каталог демонстрационный; постоянные лоты, инвентарь, передача предметов, личные сообщения, онлайн-статусы и админ-модерация ещё не реализованы.
- Виртуальные рубли и предметы не имеют денежной стоимости и не выводятся в реальные деньги.
- Жалобы записываются в базу, но очередь модерации и автоматические санкции ещё не реализованы.
