# Lootora Clicker

Lootora — браузерная dark-fantasy clicker RPG. Игрок сражается с боссами, усиливает оружие, получает предметы семи редкостей, собирает питомцев, проходит подземелья и бесконечную башню, общается и соревнуется с другими охотниками.

## Игровые системы

- Бой с семью тематическими боссами: каменный страж, демон, ледяной дракон, король бездны, космическое существо, архидемон и император драконов.
- Урон, критические удары, автоатака, уровни, опыт, золото и улучшения.
- Дроп предметов семи редкостей: обычной, редкой, сверхредкой, эпической, мифической, легендарной и секретной.
- Модификаторы предметов, инвентарь и питомцы с бонусом к золоту.
- Ежедневное задание, подземелья и башня с масштабированием сложности.
- Профиль охотника, таблица лидеров, общий чат, гильдии и рейтинговое асинхронное PvP.
- Локальное сохранение для гостя и отдельное сохранение для каждого аккаунта; облачная синхронизация через Supabase.

## Редкости и выпадения

Вес выпадения применяется внутри пула, доступного конкретному боссу. Слабые боссы не выдают высокие редкости; более сильные постепенно открывают новые уровни предметов.

| Редкость | Базовый вес |
|---|---:|
| Обычная | 58% |
| Редкая | 28% |
| Сверхредкая | 11% |
| Эпическая | 3% |
| Мифическая | 0,8% |
| Легендарная | 0,18% |
| Секретная | 0,02% |

## Подключение базы данных

Проект использует Supabase Auth, Postgres, RLS и RPC.

SQL-файлы выполняются в следующем порядке:

1. [supabase-clicker.sql](supabase-clicker.sql) — сохранения, профиль, чат и таблица лидеров.
2. [supabase-social.sql](supabase-social.sql) — гильдии, участники и PvP.
3. [supabase-hardening.sql](supabase-hardening.sql) — исправления схемы чата, безопасная публичная проекция таблицы лидеров, политики и индексы.

Для уже настроенного экземпляра Lootora эти SQL-изменения применены непосредственно к проекту Supabase. Файл `supabase-hardening.sql` сохранён в репозитории для воспроизводимости и новых окружений.

## Авторизация и конфигурация

В клиенте используется только публичный Supabase publishable key. Секретный ключ и `service_role` в браузер не помещаются.

В Supabase → Authentication → URL Configuration в качестве Site URL и Redirect URL должен быть указан адрес:

`https://vpn86156-ctrl.github.io/weatherly/`

## Важные ограничения

- PvP сейчас — асинхронный рейтинговый матч с серверной фиксацией результата, а не real-time бой с управлением персонажами.
- Гильдии и очередь PvP используют реальные таблицы и серверные RPC.
- Предметы и золото являются только внутриигровыми данными. Реальные платежи, вывод средств и торговая площадка не подключены.
- Локальные проверки и GitHub Actions не заменяют браузерные end-to-end тесты с несколькими реальными аккаунтами.

## Разработка и публикация

Сайт публикуется через GitHub Pages из ветки `main`. GitHub Actions запускает `node tests/smoke.mjs` перед каждой публикацией. Smoke-тест проверяет синтаксис встроенного JavaScript, необходимые DOM-элементы, обработчики действий, рендеринг боссов и ключевые регрессии сохранений.
